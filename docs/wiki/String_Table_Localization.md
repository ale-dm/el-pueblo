# String Table Localization

Fuente: https://town-of-salem.fandom.com/wiki/String_Table_Localization

Hey guys,
PyromonkeyGG here! We need your help to translate the game into other languages! Below you will find links to other pages on the wiki which contain our XML Data to translate for each language.

For these XMLs only replace the text between the <Text></Text> tags.

You can view the English version of the XML in one window and edit the page for the language you speak in another. Please only help with the translations if you are fluent in both the language you are translating to as well as English. If you see a word or phrase that is incorrect, please correct it!

Note that some of the Translations are incomplete, so if you wish to translate the game, but see your language already here, that does not mean it has been fully translated!

Thanks for your help!
