# Host

Fuente: https://town-of-salem.fandom.com/wiki/Host

The Host is the first person who joins the lobby (unless repicked), and their job depends on the game mode. In Custom Mode or Rapid Mode, the Host picks the role list for the game. The Start button will not be usable until 7 players have joined, including the Host. In all other modes, the Host has no real ability from the other players. There are no hosts in Ranked queues.

If the Host leaves the lobby, a random player will be assigned to be the new Host.

Whoever the host is in the lobby list of players will be marked with a crown next to their Lobby Icon. The lobby must fill to the maximum amount of players (15) to start. In Classic Custom, Coven Custom, or Rapid Mode, the host may start the game with 7-14 players (game starts automatically at 15).

Custom Mode/Rapid Mode[]

In Custom Mode and Rapid Mode, the Host has the task of picking which roles will be used in the game. They may pick any 15 of the 35 roles (47 with the Coven Expansion. The only exceptions are Juggernaut and Pestilence), or they may select any alignment other than Mafia Killing (as well as Coven Evil in the Coven Expansion. To add Coven Evil, use Random Coven) to add to the game.

Because the roles are decided by the host of the game instead of by the game itself, some strange role setups may come into play. For example, one could create a game which consists mostly of Neutrals, or a game with no killing roles on the Town side.

There are a few requirements for Custom Modes or Rapid Mode. If they are not followed, the Host will not be able to start the game unless corrected.

Hard Adds[]

These are displayed in a red-text message to the chat, visible to the host only unless specified otherwise

"There must be at least 7 players to start the game" - This message is displayed in the chat if the host attempts to start the game with less than 7 players are in the lobby.

"[Role] is limited to 1 per game." - This message displays if the Host attempts to add more than 1 of a Unique Role. The role will not be added.

"[Role/Rolebucket] is limited to 6 per game." - This message displays if the Host attempts to add more than 6 of a non- Unique Role or rolebucket. The role will not be added.

However, rolebuckets do not count towards this limit. This can cause more than 1 of a Role to spawn with the Town Killing, Neutral Chaos and Neutral Evil (Coven only) or Neutral Benign (Classic only) buckets.

"[Alignment] is limited to 4 per game." - This message displays if the Host attempts to add more than 4 of Mafia/ Coven/ Vampire roles/rolebuckets. Neutral Chaos and Random Neutral buckets do not count toward this limit. The role will not be added.

"Any is limited to 4 per game." - This message displays if the Host attempts to add more than 4 of the Any bucket.

If you want to play with more Any roles, All Any and Coven All Any are perfect for that. In addition, they are one of the few gamemodes that consistently fill up as of 2026.

"Start countdown failed. Invalid Role Selection." - This occurs if a player joins the lobby in the middle of the start countdown. This message is visible to all players.

"Start countdown failed. The number of players selected does not match the roles present." - This occurs if a player leaves the lobby in the middle of the start countdown. This message is visible to all players and is possible in all game modes.

Soft Adds[]

These will be visible in a dialog box above the role menu, visible only to the host.

"The number of players does not match the number of roles selected." - This means that the number of roles in the host's rolelist is not the same as the number of players in the game.

"You cannot start the game without opposing factions." This can happen if two of the following criteria are met:

There is at least one Town role or bucket.

There is at least one Mafia role or bucket.

There is at least one Coven role or bucket.

There is at least one Arsonist.

There is at least one Serial Killer.

There is at least one Vampire.

There is a Werewolf.

There is a Plaguebearer.

 Neutral Benign and Neutral Evil roles do not add to this faction counter, and neither do their rolebuckets.

 Witch is the exception: The existence of a Witch satisfies the Opposing Factions requirement on their own.

However, the game does not check for an autowin on Day 1, even if there's a Witch and six Survivors.

The Random Neutral Bucket also doesn't add to the counter, due to the possibility of there being a Neutral Benign or Neutral Evil.

The Neutral Chaos rolebucket doesn't count as a faction, even if there is already a Pirate.

The Neutral Killing bucket does not count against another Neutral Killing bucket, but does count against a Arsonist, Serial Killer, Vampire, Werewolf, Mafia (of any type), Coven (of any type), or Plaguebearer.

A combination of Town roles/buckets, Neutral Killing buckets, (and any non-factional roles) will not be able to start. It is unclear why.

"You cannot have the Mafia without the Godfather or Mafioso." - Specific Mafia roles cannot be added without a Mafioso, Godfather, or Mafia rolebucket.

"You cannot have a Vampire Hunter without Vampires." - You cannot have the Vampire Hunter role without the Vampire role being present.

The host may also enable Anonymous Voting. As the name suggests, this hides which player voted a certain person.

Repicking[]

Sometimes there are a number of people dissatisfied with the roles the Host has picked. In that case, the command "/repick" may be used. If enough people choose to use the command the Host will be randomly repicked and, to the hopes of the mob, do as the majority wishes.

It should be noted that groups of friends do have the ability to abuse the /repick feature so that one of their friends will get the Host and play the game they wish.

After joining a lobby, you must wait 10 seconds before voting to repick the host.

The Host can repick themselves, but it will have no effect.

If there are less than 7 people in the lobby, repicking will have no effect.

Repicking in Non-Custom Lobbies[]

Being the Host changes nothing in games with a defined role list. However, many people still choose to repick the Host, for the following reasons:

The lobby is taking a long time.

The Host is unpopular or said something controversial.

The player is bored.
